# Local onboarding flow

New local workspaces start a resumable five-step setup: business details, organization model, template suggestion, local team/Doat guidance, and completion. It is stored inside the versioned Gwira local workspace state. Existing workspaces migrate as completed so no existing user is forced through setup.

The selected organization model is applied locally. Templates remain suggestions: the app does not invent departments, employees, Doats, invitations, accounts, providers, or successful execution. Invitations and cloud account setup are unavailable pending authenticated backend support.
