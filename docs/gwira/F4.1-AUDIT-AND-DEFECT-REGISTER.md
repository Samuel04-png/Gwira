# F4.1 Dashboard audit and defect register

## Scope and baseline

Audited the isolated M1 worktree at `codex-desktop-m1-safe-planproposals`. The original `codex-desktop` worktree was inspected read-only; no files there were edited. The provided running browser page is the original Vite renderer without Electron preload, so it throws when `window.codexDesktop` is accessed and is not a representative desktop view. Baseline visual evidence therefore comes from the isolated worktree's Electron capture harness.

Baseline verification:

- `npm run typecheck`: passed.
- `npm test`: 259 passed, 60 files.
- `npm run build`: passed; the existing large-chunk warning remains.
- `npm run test:electron-smoke`: passed.
- Electron `team-expanded` capture: graph interaction rectangle was 588 px wide at 1280x800 and 748 px at 1440x900; measured node rectangles and edge counts were inside the interaction area.

The capture and source show the outer shell has a 64 px rail, approximately 260 px navigation sidebar, a fixed 328 px inspector, and a 588 px React Flow interaction surface at 1280 px window width. The screenshot's vertical application content starts below the native inset, then has a 20 px tab strip and an approximately 140 px page header before the graph. These values are a baseline, not design targets.

## Architectural risks and implementation plan

1. **Application chrome and Electron title bar:** the macOS `hiddenInset` and Windows `titleBarOverlay` options have platform-specific behavior. Integrating tabs cannot cover the native traffic-light or system-control areas, and drag regions must not include clickable tabs.
2. **Legacy Codex navigation:** the rail, project sidebar, conversation history and shared session state are used by existing coding-agent workflows. Removing the rail must preserve each unique route/action and must not create independent session state.
3. **React Flow viewport:** panel and shell changes must preserve manual pan/zoom and avoid `fitView` on every selection or content update. Graph edge truth remains record-derived.
4. **Inspector safety:** local edit/create is not hosted authorization. Keep approval decisions, arbitrary handoff changes, destructive actions, and Apply unavailable.

Implementation order:

- **F4.1A:** application-level chrome, safe tab interactions, destination parity, and navigation density; capture/inspect before moving on.
- **F4.1B:** accurate workspace/objective header, compact layout, truthful view availability, and development-only fixture controls.
- **F4.1C:** graph orientation, initial fit/resize, node/status/edge hierarchy.
- **F4.1D:** responsive contextual inspector, Team/Activity, type-appropriate information, safe actions.
- **F4.1E:** token/a11y cleanup, D-01–D-53 resolution evidence, full tests and Electron screenshots at required sizes.

The F4.1 master spec supersedes conflicting visual suggestions in the supporting audit: square avatars remain, and the right inspector remains selection-aware rather than retaining permanent Team/Activity tabs while a node is selected.

## Global shell unification (follow-up)

Root cause of the duplicate Dashboard/sidebar: `.shell` was offset by a 38px margin strip with a `position: fixed` Back/Forward toolbar floating over it, the tab bar lived inside `WorkspaceShell` (below the strip), `ProjectSidebar` embedded the People & Doats sidebar only on the Dashboard and kept its own collapse state, and the My Work task panel was `position: fixed` over the tab bar. Three stacked headers and per-page sidebar content followed.

Fixes: single `GlobalTopBar` in a CSS grid row above sidebar and page (`shell.css`); one route registry (`WORKSPACE_ROUTES`) drives sidebar and tab destinations; sidebar content identical on every page with shell-owned collapse state and a narrow overlay; task panel docked inside the page area; legacy tab/toolbar CSS removed; dark legacy view background replaced with the shared token.

Verification: typecheck clean, 265/265 tests (new `tests/workspaceRoutes.test.ts`), Electron smoke exit 0, `npm run capture:shell` (1280x800, 1440x900, 900x700, 780x640) with shell assertions passing; screenshots in `artifacts/workflow/shell`.

Remaining: relationship inspector "Dependency" label flush to panel edge; Team tab "Idle 1 +" row; at 780px the inspector takes about half the width; legacy dead `.ghost-button` CSS still in `styles.css`.
